# compression-policy

Politica:
- memoria recente pode ser detalhada.
- memoria antiga deve virar summary.
- duplicacao entre `MEMORY`, `LEARNINGS` e docs deve virar link.
- contexto de projeto nao entra na `.codex` global.

Gatilhos:
- arquivo > 2k tokens
- repeticao em 2+ lugares
- learnings historicos sem curadoria
