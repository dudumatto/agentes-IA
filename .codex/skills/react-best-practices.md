# react-best-practices

- Estado obrigatório: `loading / error / empty / success`.
- Evitar race conditions em fetch (cancel/cleanup quando aplicável).
- Não duplicar lógica entre páginas; extrair hooks/services.
- Consumir contrato de API literalmente (nomes, status, payload).
- A11y mínima: foco visível, labels, teclado.
