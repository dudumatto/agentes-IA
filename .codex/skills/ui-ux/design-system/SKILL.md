# design-system

Use quando: tokens/tema/componentes começam a divergir.

Regras:
- tokens > overrides por página
- escala: spacing `4/8/12/16/24/32/48/64`
- estados coerentes (hover/active/disabled/focus)
- motion: `150–250ms` + `prefers-reduced-motion`

Entrega:
- lista de tokens/variantes a criar/ajustar
- 1 checklist curto de validação visual
