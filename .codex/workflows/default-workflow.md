# default-workflow

1. Identificar objetivo + paths.
2. Rodar `routing/semantic-dispatch.md`.
3. Selecionar agentes minimos (1 owner + especialistas).
4. Rodar analise curta (3-7 bullets por agente).
5. Consolidar decisoes + riscos.
6. Implementar mudancas minimas.
7. Validar (test/build/checklist).
8. Registrar memoria se reutilizavel.

Formato: `templates/output-format.md`.
