# default-workflow

1) Identificar objetivo + paths.
2) Selecionar agentes mínimos (1 owner + necessários).
3) Rodar análise curta (3–7 bullets por agente).
4) Consolidar decisões + riscos.
5) Implementar mudanças mínimas.
6) Validar (test/build/checklist).
7) Registrar memória (se reutilizável).

Formato: `templates/output-format.md`.
